## Blog Post Template Reference

Every blog post file follows this exact structure. Use `app/blog/arc-flash-hazard-analysis/page.tsx` as the canonical reference. Key sections:

1. **Imports:** `Metadata`, `Link`, `Navigation`, `BlogPostingJsonLd`, `BreadcrumbJsonLd`
2. **Metadata export:** title, description (expanded for SEO), keywords array (10 terms), canonical URL, openGraph
3. **HeroIllustration():** SVG `viewBox="0 0 400 180"` with `className="w-full h-40 md:h-48"` and aria-label
4. **Default export page function** containing:
   - `<Navigation />`
   - BreadcrumbJsonLd (Home > Blog > Post Title)
   - BlogPostingJsonLd (headline, description, date, canonical, keywords)
   - Breadcrumb nav
   - Hero with illustration, category badge, title, meta info
   - Content sections with `<h2>`, `<h3>`, tables, lists, code examples
   - Footer CTA (App Store + Explore Features)
   - Related Articles (4 links to existing posts)
   - Footer nav

**Category colors for badges:**
